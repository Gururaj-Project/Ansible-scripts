🖥️✨ Ansible Server Availability Checker 🔔✅

## 🚀 Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/Gururaj-Project/Ansible-scripts.git
   cd Ansible-scripts
2. Update hosts.ini
   Add all server IPs or hostnames you want to check.

3. Update group_vars/all.yml
   Add your webhook URL or any other required variables.

4.  Run the playbook
    ```
    ansible-playbook -i hosts.ini ping-playbook.yml
    ```
